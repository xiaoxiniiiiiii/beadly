# BEADLY 饰品商城

React + Vite + Express。当前分支 main。所有源文件使用 UTF-8；纯色配色，无渐变。

## 运行

```sh
npm i
npm run dev
```

首页：http://localhost:5180/
后台：http://localhost:5180/#admin
客户订单查询：http://localhost:5180/#track

```sh
npm run build
npm run check
```

生产模式：先构建，然后在 PowerShell 中运行 `$env:NODE_ENV='production'; npm start`。端口通过 PORT 环境变量配置，默认 5180。监听所有网卡，仅在本机或网络权限允许的局域网内可用，尚未发布公网。

## 管理员

第一次启动自动生成随机初始密码，保存于 `server/data/initial-login.txt`，账号 admin。密码以 scrypt 加盐哈希保存，不在前端代码中。登录会话使用 HttpOnly、SameSite Cookie，8 小时过期。后台可修改商品名称、价格、库存，查看订单及修改发货状态和物流编号。仅有一个本地管理员账号，尚无客户密码登录。

## 实现范围

- 4 类商品，每类 18 款，共 72 款，价格 24–110 美元，均在要求的 20–300 美元范围内。
- 72 张独立 AI 展示图及一张首页图，全部本地 WebP；未使用第三方产品品牌。
- 搜索、分类、排序、收藏、详情、购物车数量调整、Add to Cart 自动打开侧栏、Buy Now 直接结算。
- 下单后跳转内部演示支付页，显示 PayPal、Visa 和信用卡选项；不采集卡号，不真实扣款。服务端核算金额，演示支付重复提交不重复扣库存。
- 订单和商品持久化到本地 JSON，订单查询需要订单号和邮箱。
- 公司名称、邮箱、电话、地址使用用户提供资料。注册号未提供，页脚明确标注待核实。
- 关于我们、付款、退货退款、取消、发货、订单追踪、17 节服务条款、隐私和 DMCA 页面。

## 上线前必需配置

本地版本是演示商城，并非真实支付系统。需要先核实商品实际材质、尺寸、库存、产品知识产权、公司注册号、经营及物流范围，并审定政策；再接入法人对应的 PayPal/银行卡商户账号、服务端支付创建和已验签 webhook，启用 HTTPS、数据库备份和生产数据保留机制。不要向聊天发送支付密钥。

本地 JSON 存储适合演示单实例，非高并发多实例部署。演示支付不会真实发货；后台金额为演示订单总额，不是营业收入。政策是店铺草案，不代表已完成合规审查。

## Git 上传规则

`.gitignore` 忽略 node_modules、dist、环境密钥、运行数据库、初始密码、临时资料和日志；保留 package-lock.json、src、server 源码、public 图片和脚本。不要提交 `server/data`、`.env`、用户订单或支付密钥。未自动推送 GitHub。

已运行构建和 28 项接口/目录检查。遵照用户要求未进行浏览器验证。参考模板 HTML 读取确认白底、黄色强调色（#ffd21d）、灰黑文字，采用相近商城分区而未复制第三方品牌和商品内容。
